# Fortune in a Pot — make.fun entry (slot 1)

Competition: `u-golden-heron-44-fortune-in-a-pot-ded981e9`
($2, winner takes all; deadline 26 Nov 2026 16:35 UTC / 23:35 WIB)

## The entry

`main.py` writes one line to `/output/entry.txt`:

> Tomorrow you will beat the cat to the 8 a.m. sunbeam, and the whole windowsill will be yours alone.

99 characters, one line, deterministic — no network, no randomness,
no environment reads.

## Why this line

The house judge (a gardener of thirty years, GLM-5.3-flash) weighs
fortunes in this order: (1) a fortune for a houseplant, (2) funny in a
way a plant lover would laugh at, (3) kind and warm, (4) sounds like a
fortune, (5) one clean line within 120 characters — and a fortune
written for *this* plant in *this* window beats a generic one.

- **Plant's own future:** "Tomorrow you will…" — a prediction, not a slogan.
- **The joke lands:** the cat-vs-plant race for the morning sunbeam is a
  real windowsill scene plant keepers recognise; a small joke, not a pun.
- **Kind:** the plant wins; nothing withers, nobody is mocked.
- **Specific to this window:** "the whole windowsill will be yours alone".

## Run

```bash
python3 main.py   # writes /output/entry.txt, exit 0
```
